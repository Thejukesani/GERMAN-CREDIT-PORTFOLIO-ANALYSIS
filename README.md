# German Credit Portfolio Analysis 📊

An interactive one-page dashboard built to analyze **1,000 loan applicants** using data analysis, SQL/Python-driven insights, and interactive visualizations.

The project focuses on understanding applicant characteristics, credit demand, loan duration, account status, and other factors that can support credit portfolio analysis.

---

## 📌 Project Overview

The **German Credit Portfolio Analysis** dashboard provides a visual summary of loan applicant data and highlights important patterns in credit demand and applicant profiles.

The dashboard was designed as a **single-page interactive analytics dashboard**, making it easy to view key metrics and insights in one place.

---

## 🎯 Objectives

- Analyze loan applicant characteristics
- Understand credit demand by loan purpose
- Compare applicants across housing types
- Analyze applicant distribution by gender
- Identify job/skill-level distribution
- Study average credit across different loan durations
- Analyze savings account status
- Analyze checking account status
- Present key insights through an interactive dashboard

---

### Visualizations

---

## 🔍 Key Business Questions

This project answers questions such as:

1. Which loan purposes have the highest credit demand?
2. Which housing type has the largest number of applicants?
3. What is the gender distribution of applicants?
4. How are applicants distributed by job skill level?
5. Does average credit amount vary with loan duration?
6. What percentage of applicants have different savings account statuses?
7. How does checking account status relate to average credit?

---

## 📈 Business Insights

The dashboard can help financial institutions understand:

- Customer borrowing patterns
- Credit demand across different purposes
- Applicant demographics
- Account and financial status
- Loan duration patterns
- Potential areas for portfolio segmentation

These insights can support **credit risk analysis, customer segmentation, and lending strategy decisions**.
